I am pleased to confirm that in September I will be taking part in two events which are scheduled so far.

My FinOps on Microsoft Azure session is selected for the [Azure Back to School 2021](https://azurebacktoschool.github.io/) series, organised by the fantastic [Dwayne Natwick](https://twitter.com/DwayneNcloud) who is a fellow Microsoft Azure MVP.

My second session will be on the 21st September with the [Azure Thames Valley User Group](https://www.meetup.com/Azure-Thames-Valley/). My session Building Serverless APIs with Azure Functions and API Management looks at how we can use Azure Functions and OpenAPI to build RESTful APIs using Azure API Management.

I look forward to speaking at both of these events and look forward to sharing more with the community.
